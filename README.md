# مِعيار AI — المراجع الذكي للمخططات الكهربائية

نموذج أولي مقدم إلى **الهاكاثون الهندسي SCE 2026** ضمن:

- المسار: التطوير الهندسي
- التحدي: التدقيق الآلي والامتثال للأكواد

## الفكرة

منصة عربية تساعد المهندس على رفع المخطط الكهربائي، استخراج مكوناته، تشغيل فحوصات هندسية قابلة للتتبع، إظهار مواقع المخالفات، واقتراح إجراءات تصحيحية مع إبقاء الاعتماد النهائي للمهندس المرخص.

## تجربة النموذج

افتح `index.html` أو استخدم GitHub Pages، ثم اختر **استخدام المخطط التجريبي** واضغط **تشغيل التدقيق الذكي**.

## نطاق الـMVP

- واجهة رفع ملفات PDF والصور
- عارض مخطط أحادي تجريبي
- تصنيف النتائج إلى حرج وتحذير ومجتاز
- ربط الملاحظة بموقعها على المخطط
- درجة امتثال وتقرير قابل للطباعة
- تصميم عربي متجاوب يعمل دون خادم

> تنبيه: مراجع الكود في النموذج وصفية. يجب ربط المنتج النهائي بنسخة مرخصة ومحدثة من الكود، والتحقق من القواعد بواسطة مهندسين مختصين.

## خارطة التطوير

1. استخراج النصوص والرموز من PDF/CAD
2. بناء نموذج بيانات كهربائي موحد
3. محرك قواعد هندسية قابل للإصدار والتدقيق
4. حسابات الأحمال والحماية وهبوط الجهد
5. ربط النتائج ببنود الكود المرخصة
6. دورة اعتماد Human-in-the-loop
