# مِعيار AI  منصة الامتثال الكهربائي

نموذج منتج احترافي مقدم إلى **الهاكاثون الهندسي SCE 2026** ضمن مسار التطوير الهندسي وتحدي التدقيق الآلي والامتثال للأكواد.

## المشكلة

مراجعة المخططات الكهربائية عملية يدوية متكررة، وتوزّع الملاحظات بين ملفات وجداول ورسائل يجعل القرار الهندسي بطيئًا وصعب التتبع.

## الحل

مِعيار AI يحول المخطط إلى نموذج بيانات هندسي، يشغّل حسابات وقواعد امتثال قابلة للتفسير، يربط كل ملاحظة بموقعها ودليلها، ثم يضع القرار النهائي بيد المهندس المرخص.

## ما يمكن تجربته الآن

- عارض مخطط أحادي تفاعلي مع تحديد مواقع المخالفات
- سجل ملاحظات مرتب حسب الخطورة والثقة والموقع
- تفاصيل الأدلة، القاعدة، والإجراء التصحيحي
- معالجة الملاحظات وتحديث درجة الامتثال مباشرة
- ورقة حسابات قابلة للتحرير لتيار التصميم وهبوط الجهد والتنسيق
- مكتبة قواعد بإصدارات ومعرّفات قابلة للتتبع
- مساحات للمشاريع والتقارير
- تقرير مراجعة قابل للطباعة
- تصميم عربي RTL متجاوب

## المعمارية المستهدفة

`PDF / CAD → OCR + Computer Vision → Electrical Graph → Deterministic Rule Engine → Explainable Findings → Engineer Approval`

يعتمد النموذج الحالي على بيانات تجريبية ومحرك حسابات يعمل داخل المتصفح لإثبات تجربة المنتج. النسخة الإنتاجية تربط خدمات استخراج PDF/CAD وقاعدة بيانات للإصدارات وسجل تدقيق غير قابل للتلاعب.

## إطار الامتثال

الإطار الأساسي المقترح هو **SBC 401-2024**، مع SBC 601/602 لكفاءة الطاقة ومتطلبات شركة الكهرباء السعودية وSASO عند انطباقها.

> لا يحتوي المستودع على نصوص محمية من الكود. معرّفات القواعد تجريبية، وتُربط البنود الرسمية فقط بعد الحصول على نسخة مرخصة والتحقق من القواعد بواسطة مهندسين مختصين.

## التشغيل

المشروع واجهة ويب مستقلة دون حزم أو خادم:

1. افتح `index.html` محليًا، أو استخدم GitHub Pages.
2. افتح ملاحظة لعرض الأدلة والإجراء المقترح.
3. عدّل الحمل أو طول الكابل أو مقطعه في ورقة الحسابات.
4. شاهد الحسابات وقرار القاعدة ودرجة الامتثال تتحدث مباشرة.

## الخطوات الإنتاجية

1. محلل PDF وDXF/IFC واستخراج الرموز والجداول
2. نموذج بيانات كهربائي موحد وعلاقات graph
3. خدمة قواعد بإصدارات وموافقات هندسية
4. حسابات short-circuit وselectivity وarc-flash
5. ربط البنود المرخصة وتحديثات الإصدارات
6. حسابات المستخدمين والصلاحيات والتوقيع الإلكتروني
7. تكامل BIM/CDE وواجهات API للجهات الاستشارية
